Annotations
 
Das Description-Element legt die Beschreibung fest, die in den Vertriebssystemen angezeigt werden soll.
Eine Beschreibung kann in mehreren Sprachen erfolgen.

Beispiel für die Beschreibung einer Verpflegung:
<Description Language="DE">Übernachtung mit Frühstück</Description>
 
The Description element specifies the description to be shown in the sales systems.
A description can be given in multiple languages.

Example for the description of a board:
<Description Language="EN">Bed and breakfast</Description>

Language restriction of xs:string DE optional 
Das Language-Attribut legt den Sprachcode der Beschreibung fest.

                            Mögliche Werte:
                            * Ein zweibuchstabiger Code gemäß ISO 639-1, allerdings in Großbuchstaben. Beispiel: "EN" (Englisch), "DE" (Deutsch).
                            * Der Wert "**". Dieser Wert steht für eine vorher festgelegte Standardsprache, die als Ersatz für nicht vorhandene Beschreibungen verwendet wird.
                            * Ein fünfbuchstabiger Code gemäß ISO-639-1 und ISO-3166-1. Format: [sprache]_[region]. Beispiel: "en_US" (Englisch, USA), "de_DE" (Deutsch, Deutschland). Seit Version 2.8.71 und 2.9.
 
The Language attribute specifies the language identifier of the description.

                            Possible values:
                            * A two-letter code according to ISO 639-1, but in capital letters. Example: "EN" (English), "DE" (German).
                            * The value "**" is possible. This value stands for a previously defined default language that serves as a fall-back for unavailable descriptions.
                            * A five-letter code according to ISO-639-1 and ISO-3166-1. Format: [language]_[region]. Example: "en_US" (English, USA), "de_DE" (German, Germany). Since version 2.8.71 and 2.9.
