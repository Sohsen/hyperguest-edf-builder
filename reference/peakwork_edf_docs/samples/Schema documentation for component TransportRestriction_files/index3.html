Complex Type TransportRestriction
Namespace http://www.vilauma.de/edf/SalesControl
Annotations
 
Das TransportRestriction-Element definiert eine Einschränkung, die sich auf einen Flug bezieht.

Die Attribute eines TransportRestriction-Elements sind untereinander mit einem logischen UND verknüpft.
 
The TransportRestriction element defines a restriction that is related to a flight.

The attributes of a TransportRestriction element are always joined by a logical AND.

Airline xs:string optional 
Das Airline-Attribut legt das Airlinekürzel dieses TransportRestriction-Elementes fest.
				
Der gültige Wert ist ein String von maximal 4 Zeichen Länge.
 
The Airline attribute specifies the airline abbreviation of this TransportRestriction element.
				
A string up to a max. of 4 characters is valid.

Das ArrivalAirport-Attribut legt fest, für welchen Zielflughafen das TransportRestriction-Element gültig ist.

Der Wert ist ein 3-buchstabiger IATA-Code.
 
The ArrivalAirport attribute specifies for which arrival airport the TransportRestriction-Element is valid.

The value is a three-letter IATA code.

Das Attribut wird im PXB-Merge-Prozess ab der Player-Version 2.10.0 unterstützt.
 
The ArrivalTimeMax attribute specifies the latest possible arrival time. Format: hh:mm:ss
This attribute is supported in the PXB merge process from the Player version 2.10.0

BookingClass xs:string optional 
Das BookingClass-Attribut legt fest, für welche Buchungsklasse das TransportRestriction-Element gültig ist.
Der gültige Wert ist ein String von maximal 4 Zeichen Länge.
 
The BookingClass attribute specifies for which booking class the TransportRestriction element is valid.

DepartureAirport restriction of xs:string optional 
Das DepartureAirport-Attribut legt fest, für welchen Startflughafen das TransportRestriction-Element gültig ist.

Der Wert ist ein 3-buchstabiger IATA-Code.

Beispiel:
<TransportRestrictions>
<TransportRestriction DepartureAirport="DUS"/>
</TransportRestrictions>
Dies verwirft alle Flüge (Hinflüge und Rückflüge) ab DUS.

Beispiel:
<TransportRestrictions>
<TransportRestriction Type="Outbound" DepartureAirport="DUS"/>
</TransportRestrictions>
Dies verwirft alle Hinflüge ab DUS.
 
The DepartureAirport attribute specifies for which departure airport the TransportRestriction element is valid.

The value is a three-letter IATA code.

Example:
<TransportRestrictions>
<TransportRestriction DepartureAirport="DUS"/>
</TransportRestrictions>
This discards all flights (outbound and inbound) departing from DUS.

Example:
<TransportRestrictions>
<TransportRestriction Type="Outbound" DepartureAirport="DUS"/>
</TransportRestrictions>
This discards all outbound flights departing from DUS.

FlightNumber xs:string optional 
Das FlightNumber-Attribut legt die externe Flugnummer des Segments fest. Beispiel: AB9564
				
Der gültige Wert ist ein String von maximal 7 Zeichen Länge.
 
The FlightNumber attribute specifies the external flight number of the segment. Example: AB9564
				
A string up to a max. of 7 characters is valid.
MinConnectingTimeDuration xs:unsignedShort optional 
Das MinConnectingTimeDuration-Attribut legt die minimale Transferdauer in Minuten zwischen zwei Flugsegmenten fest, ab der die Restriktion gilt. Bei mehreren Flugsegmenten wird die maximale Transferdauer aller Segmente ausgewertet.
Das Attribut wird ausschließlich im PXB-Merge-Prozess ab der Player-Version 2.37.0 unterstützt.
 
The MinConnectingTimeDuration attribute specifies the minimum connecting time in minutes between two flight segments which results in validity of the restriction. In case of multiple segments, the maximum connecting time of all segments is evaluated.

Example:
<TransportRestrictions>
<TransportRestriction MinConnectingTimeDuration="60"/>
</TransportRestrictions>
This discards all flights with connecting times between two segments greater or equal than 60 minutes. 
Example flight with 3 segments: (seg1: departure=12:30, arrival=14:15; seg2: departure=15:10, arrival=18:50; seg3: departure=19:50, arrival=22:35); this flight would be discarded with the restriction above, because the maximum connecting time of all segments is 60 minutes (seg1->seg2: 55 min., seg2->seg3: 60 min.). 

					This attribute is only supported in the PXB merge process from the Player version 2.37.0
MinSegments xs:integer optional 
Das MinSegments-Attribut legt die Anzahl der Flugsegmente fest, ab welcher das TransportRestriction-Element gilt.

Beispiel:
<TransportRestrictions>
<TransportRestriction MinSegments="2"/>
</TransportRestrictions>
Dies verwirft alle Flüge mit zwei oder mehr Segmenten.

Mögliche Werte: "1", "2", "3".

Das Attribut wird im PXB-Merge-Prozess ab der Player-Version 2.10.0 unterstützt.
 
The MinSegments attribute specifies the minimum number of flight segments of the FlightRestriction element.

Example:
<TransportRestrictions>
<TransportRestriction MinSegments="2"/>
</TransportRestrictions>
This discards all flights with two or more segments.

Possible values: "1", "2", "3".

This attribute is supported in the PXB merge process from the Player version 2.10.0
Type TypeEnum optional 
Das Type-Attribut legt fest, ob das TransportRestriction-Element für den Hinflug oder den Rückflug gilt.

Mögliche Werte:
* Inbound: Rückflug
* Outbound: Hinflug

Beispiel:
<TransportRestrictions>
<TransportRestriction Type="Outbound" DepartureAirport="DUS"/>
</TransportRestrictions>
Dies verwirft alle Hinflüge ab DUS.
 
The Type attribute specifies, whether the TransportRestriction element applies to an outbound or an inbound flight.
Possible values:
* Inbound
* Outbound

Example:
<TransportRestrictions>
<TransportRestriction Type="Outbound" DepartureAirport="DUS"/>
</TransportRestrictions>
This discards all outbound flights departing from DUS.

Attribute TransportRestriction / @MinConnectingTimeDuration
Namespace No namespace
Annotations
 
Das MinConnectingTimeDuration-Attribut legt die minimale Transferdauer in Minuten zwischen zwei Flugsegmenten fest, ab der die Restriktion gilt. Bei mehreren Flugsegmenten wird die maximale Transferdauer aller Segmente ausgewertet.
Das Attribut wird ausschließlich im PXB-Merge-Prozess ab der Player-Version 2.37.0 unterstützt.
 
The MinConnectingTimeDuration attribute specifies the minimum connecting time in minutes between two flight segments which results in validity of the restriction. In case of multiple segments, the maximum connecting time of all segments is evaluated.

Example:
<TransportRestrictions>
<TransportRestriction MinConnectingTimeDuration="60"/>
</TransportRestrictions>
This discards all flights with connecting times between two segments greater or equal than 60 minutes. 
Example flight with 3 segments: (seg1: departure=12:30, arrival=14:15; seg2: departure=15:10, arrival=18:50; seg3: departure=19:50, arrival=22:35); this flight would be discarded with the restriction above, because the maximum connecting time of all segments is 60 minutes (seg1->seg2: 55 min., seg2->seg3: 60 min.). 

					This attribute is only supported in the PXB merge process from the Player version 2.37.0
