Das Rounding-Element definiert die Rundungsregeln des übergeordneten Elementes.
 
The Rounding element defines the rounding rules of the parent element.

Attributes
QName Type Fixed Default Use Annotation
Mode RoundingEnum No optional 
Das Mode-Attribut legt fest, wie gerundet wird.

Mögliche Werte:
* Up: aufrunden
* Down: abrunden
* Commercial: kaufmännisch runden
* No: es wird nicht gerundet
 
The Mode attribute specifies how a figure is rounded off.

Possible values:
* Up: round up
* Down: round off
* Commercial: round off to two positions behind the decimal point
* No: no rounding
Scope ScopeEnum Person optional 
Das Scope-Attribut legt fest, wann gerundet werden soll.

Mögliche Werte:
* Room: Der Preis des Zimmers wird gerundet.
* Day: Der Preis wird tageweise gerundet
* Person: Der Preis wird pro Person gerundet.

Beispiel für Scope="Day":
* Tagespreis: 30 EUR
* Dauer: 7 Tage
* Rabatt: 15%
Schritte:
1) 30 EUR - 15% = 25,5 EUR
2) Rundung des Tagespreises von 25,5 EUR auf 26 EUR
3) 26 EUR * 7 Tage = 182 EUR
 
The Scope attribute specifies when to round.

Possible values:
* Room: The price of the room is rounded.
* Day: The price is rounded on a per-day basis.
* Person: The price is rounded on a per-person basis.

Example for Scope="Day":
* price per day: 30 EUR
* duration: 7 days
* reduction: 15%
Steps:
1) 30 EUR - 15% = 25.5 EUR
2) price per day is rounded from 25.5 EUR to 26 EUR
3) 26 EUR * 7 days = 182 EUR
