Element OccupancyType / Infants
Namespace http://www.vilauma.de/edf/Hotel
Annotations
 
Das Infants-Element definiert, wie Infants (Säuglinge) berechnet werden.

Wenn das Infants-Element nicht verwendet wird, bestehen keine Einschränkungen bezüglich der Infants. Infants sind in diesem Falle erlaubt und werden nicht in der Belegung gezählt.

Der Altersbereich für Infants wird nicht im Infants-Element festgelegt, sondern indirekt im Children-Element.
 
The Infants element defines how infants are calculated.

If the Infants element isn't used, there are no restrictions with regard to infants. In this case, infants are allowed and are not counted in the occupancy.

The age range for infants isn't specified in the Infants element but indirectly in the Children element.

<Occupancy ...>

</Occupancy>

The Children element defines details related to children.

The Children element does not only define the age range for children but also the other age ranges.

Example:
<Occupancy ...>
    <Children MinAge="2" MaxAge="17"/>
</Occupancy>
In this example, the Children element specifies that travellers between 2 and 17 years are children. Travellers that are younger are infants. Travellers that are older are adults.

Element OccupancyType / Bed
Namespace http://www.vilauma.de/edf/Hotel
Annotations
 
Das Bed-Element definiert Altersbeschränkungen für Betten.

Beispiel:
In einem Zimmer sind 2 normale Betten und 2 Zustellbetten erlaubt.
Das erste Zustellbett darf nur bis zu einem Alter von 12 Jahren belegt werden.
Das zweite Zustellbett darf nur bis zu einem Alter von 5 Jahren belegt werden.
Die Altersbeschränkungen zu den beiden Zustellbetten würden so geschrieben:
<Bed MinCount="3" MaxCount="3" MinAge="2" MaxAge="12"/>
<Bed MinCount="4" MaxCount="4" MinAge="2" MaxAge="5"/>

Bei AppliesToBed="ExtraBed" sind MinCount und MaxCount relativ zum ersten Zustellbett (d.h. die Zählung fängt beim ersten Zustellbett an).
Beispiel:
<Occupancy Min="3" Max="5" MinExtraBed="0" MaxExtraBed="2">
  <Bed MinCount="1" MaxCount="1" MinAge="2" MaxAge="12" AppliesToBed="ExtraBed"/>
  <Bed MinCount="2" MaxCount="2" MinAge="2" MaxAge="5" AppliesToBed="ExtraBed"/>
</Occupancy>
Hier gelten die Altersbeschränkungen für das erste und das zweite Zustellbett.

Wenn MinCount und MaxCount nicht angegeben sind, aber AppliesTo="ExtraBed", dann gilt die Altersbeschränkung nur für Zustellbetten.
Beispiel:
<Occupancy Min="3" Max="5" MinExtraBed="0" MaxExtraBed="2">
  <Bed MinAge="2" MaxAge="12" AppliesToBed="ExtraBed"/>
</Occupancy>

Wenn MinCount und MaxCount nicht angegeben sind, aber AppliesTo="All", dann gilt die Altersbeschränkung für alle Betten im Zimmer.
Beispiel:
<Occupancy Min="3" Max="5" MinExtraBed="0" MaxExtraBed="2">
  <Bed MinAge="2" MaxAge="12" AppliesToBed="All"/>
</Occupancy>
 
The Bed element defines age restrictions for beds.

Example:
In a room, 2 regular beds and 2 additional beds are permitted.
The first additional bed may only be occupied up to the age of 12.
The second additional bed may only be occupied up to the age of 5.
The age restrictions regarding the two additional beds would be written like this:
<Bed MinCount="3" MaxCount="3" MinAge="2" MaxAge="12"/>
<Bed MinCount="4" MaxCount="4" MinAge="2" MaxAge="5"/>

If AppliesToBed="ExtraBed", then MinCount and MaxCount are relative to the first additional bed (i.e. counting starts with the first additional bed).
Example:
<Occupancy Min="3" Max="5" MinExtraBed="0" MaxExtraBed="2">
  <Bed MinCount="1" MaxCount="1" MinAge="2" MaxAge="12" AppliesToBed="ExtraBed"/>
  <Bed MinCount="2" MaxCount="2" MinAge="2" MaxAge="5" AppliesToBed="ExtraBed"/>
</Occupancy>
Here, the age restrictions apply to the first and the second additional bed.

If MinCount and MaxCount are not set and AppliesTo is "ExtraBed", then the age restriction applies only to the additional beds.
Example:
<Occupancy Min="3" Max="5" MinExtraBed="0" MaxExtraBed="2">
  <Bed MinAge="2" MaxAge="12" AppliesToBed="ExtraBed"/>
</Occupancy>

If MinCount and MaxCount are not set and AppliesTo is "All", then the age restriction applies to all beds in the room.
Example:
<Occupancy Min="3" Max="5" MinExtraBed="0" MaxExtraBed="2">
  <Bed MinAge="2" MaxAge="12" AppliesToBed="All"/>
</Occupancy>
