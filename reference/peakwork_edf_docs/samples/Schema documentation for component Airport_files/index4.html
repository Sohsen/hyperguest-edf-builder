IataCode xs:string required 
Das Attribut zeigt den eindeutigen Flughafen-IATA Code.

Beispiel:
/ArrivalAirports
   /Airport IataCode="TFS" Package="true"
  /Airport IataCode="TFN" Package="true"
/ArrivalAirports
Bei diesem Beispiel kann das Hotel über die Zielflughäfen TFS und TFN angeflogen werden.
-----------------------------------------
This attribute displays the unique IATA airport code.

Example:
/ArrivalAirports
   /Airport IataCode="TFS" Package="true"
  /Airport IataCode="TFN" Package="true"
/ArrivalAirports
This example shows, that the hotel can be reached via the arrival airports TFS and TFN.
Order restriction of xs:int optional 
Das Attribute Order kennzeichnet den Hauptflughafen bzw. Gewichtung der Flughäfen. Die kleinste Ordernummer hat die höchste Gewichtung.
Ordernummer 1 steht daher für den Hauptflughafen.

Beispiel:
/ArrivalAirports
   /Airport IataCode="TFS" Package="true" Order="1"
  /Airport IataCode="TFN" Package="true" Order="2"
/ArrivalAirports
Bei diesem Beispiel kann das Hotel über die Zielflughäfen TFS und TFN angeflogen werden. Dabei hat jedoch der Zielflughafen TFS die höhere Priorität.
-----------------------------------------
The Order attribute indicates the main airport or the weighting of airports. The lowest order number has the highest weight.
Thus, order number 1 stands for the main airport.

Example:
/ArrivalAirports
   /Airport IataCode="TFS" Package="true" Order="1"
  /Airport IataCode="TFN" Package="true" Order="2"
/ArrivalAirports
This example shows that the hotel can be reached via the arrival airports TFS and TFN. The arrival airport TFS, however, has the higher priority here.
Package xs:boolean optional 
Mit dem Attribut Package wird ein Kenner gesetzt, ob der spezielle Flughafen explizit zur Bündelung von Pauschalreisen vorgesehen ist oder nicht.

Beispiel:
/ArrivalAirports
   /Airport IataCode="TFS" Package="true"
  /Airport IataCode="TFN" Package="true"
/ArrivalAirports
Bei diesem Beispiel kann das Hotel über die Zielflughäfen TFS und TFN angeflogen werden.
-----------------------------------------
The Package attribute sets an identifier showing whether or not the specific airport is explicitly intended for bundling package tours.

Example:
/ArrivalAirports
   /Airport IataCode="TFS" Package="true"
  /Airport IataCode="TFN" Package="true"
/ArrivalAirports
This example shows, that the hotel can be reached via the arrival airports TFS and TFN.
