Element GuestRestrictions
Namespace http://www.vilauma.de/edf/Hotel
Annotations
 
Das GuestRestrictions-Element ist eine Liste von GuestRestriction-Elementen.

Die GuestRestriction-Elemente eines GuestRestrictions-Elementes sind immer mit einem logischen UND verknüpft.
 
The GuestRestrictions element is a list of GuestRestriction elements.

The GuestRestriction elements of a GuestRestrictions element are always joined with a logical AND.

Attributes
QName Type Fixed Default Use Annotation
Invert xs:boolean optional 
Das Invert-Attribut legt fest, ob die Bedingung, die im GuestRestrictions-Element definiert ist, invertiert (umgekehrt) werden soll.

Mögliche Werte:
* true
* false

Ablauf:
Erst werden die GuestRestriction-Elemente des GuestRestrictions-Elementes ausgewertet.
Danach wird die Gesamteinschränkung, die daraus entstanden ist, invertiert (umgekehrt), falls Invert="true".
 
The Invert attribute specifies whether the condition defined in the GuestRestrictions element is inverted.

Possible values:
* true
* false

Workflow:
First, the GuestRestriction elements of the GuestRestrictions element are evaluated.
After that, the resulting restriction is inverted, if Invert="true".

Element GuestRestrictions / GuestRestriction
Namespace http://www.vilauma.de/edf/Hotel
Annotations
 
Das GuestRestriction-Element definiert eine personenbezogene Einschränkung.

Wenn Sie festlegen wollen, für welches Alter die Restriction gilt, müssen Sie das im Appliance-Element tun, in den Attributen MinAge und MaxAge.
 
The GuestRestriction element defines a personal restriction.

If you want to specify for which age the restriction is valid, you have to do so in the Appliance element, in the attributes MinAge and MaxAge.
