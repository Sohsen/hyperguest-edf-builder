Category xs:string optional 
The Category attribute specifies the type of content that is defined in the Paragraph element, e.g. Hotel, Room, Location, Amenities.

					For each product a description with the category Hotel must exist. Otherwise, it cannot be processed correctly in
					the Goalkeeper and ContentPlayer.

					Moreover, each combination of Category, Language and Country must be unique. If they are not unique, they might overwrite
					each other both in the Goalkeeper and ContentPlayer frontend as well as the ContentPlayer API response.
