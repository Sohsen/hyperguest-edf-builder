Element INFX
Namespace http://www.vilauma.de/edf/Hotel
Annotations
 
Das INFX-Element definiert zusätzliche Informationen, die bei der INFX-Erstellung in die Zeile geschrieben werden.

Das INFX-Element ist nur relevant, wenn man aus den EDF-Daten INFX erstellen will und die vordefinierten INFX-Formate nicht ausreichen.
 
The INFX element defines additional information, which is written into the offer line during the INFX generation.

The INFX element is only relevant if you want to generate INFX data from EDF and the predefined INFX formats aren't sufficient.
