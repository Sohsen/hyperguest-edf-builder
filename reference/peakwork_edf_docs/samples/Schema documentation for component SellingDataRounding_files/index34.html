Complex Type SellingDataRounding
Namespace http://www.vilauma.de/edf/Hotel
Annotations
 
Dieses Element legt fest, wie Preise mit Nachkommastellen zu runden sind.
 
This element specifies how prices with decimal places are rounded.
Diagram
Used by
Element HotelRoot/SellingData/Rounding
Attributes
QName Type Fixed Default Use Annotation
DecimalPlace restriction of xs:unsignedInt 0 optional 
Das DecimalPlace-Attribut legt die Anzahl der Nachkommastellen fest.
Es werden maximal 7 Nachkommastellen unterstützt. Der Standardwert ist 0 (d.h. es wird auf eine Ganzzahl gerundet).
 
The DecimalPlace attribute specifies the number of decimal places.
The maximum number of supported decimal places is 7. The defualt value is 0 (which means that the figure is rounded to an integer value).
Mode RoundingEnum No optional 
Das Mode-Attribut legt fest, wie gerundet wird.

Mögliche Werte:
* Up: Aufrunden
* Down: Abrunden
* Commercial: Kaufmännisch runden
* No: es wird nicht gerundet
 
The Mode attribute specifies how a figure is rounded off.

Possible values:
* Up: round up
* Down: round off
* Commercial: round off to two positions behind the decimal point
* No: no rounding
Scope ScopeEnum Person optional 
Das Scope-Attribut legt fest, wann gerundet werden soll.

Mögliche Werte:
* Person: Rundung auf Personenpreis
* Room: Rundung auf Zimmerpreis
* Day: Der Preis wird tageweise gerundet (z.B. Tagespreis von 30 EUR, 7 Tage, FB 15% ergibt: 30-15% = 25,5 ~ 26 EUR * 7 Tage = 182 EUR)
 
The Scope attribute specifies when to round.

Possible values:
* Person: rounding per person
* Room: rounding per room price
* Day: the price is rounded on a per-day basis (e.g. price per day 30 EUR, 7 days, EB 15% results in: 30-15% = 25.5 ~ 26 EUR * 7 days = 182 EUR)
