Backup strategies﻿

Last modified: 25 February 2026

This chapter contains backup and recovery strategies for each individual Peakwork software component. It also contains a step by step description of a best practice approach for recovering each component and the recommended starting order of components in the same stack. The Peakwork components are captured in the following order: Player, Hub, Store and D-Hub-stack.

The backup strategies recommended in this document assume that no full system backups are performed. A reinstallation of the Peakwork software and all underlying services such as MySQL and Apache is therefore required in all cases before backups can be used to restore the prior state of the system.

The Player components section describes how to back up relevant files and data for Peakwork's Player application stack. It consists of PlayerControls, Players, PSEs, PlayerBridges and INFX servers.

The section Hub-server components section deals with backup and recovery of all Hub server-related Peakwork components. This includes the Hub itself and all complimentary components like ActiveMQ.

The Store section deals with backup and recovery of all Store-related Peakwork components.

The D-Hub section deals with backup and recovery of all D-Hub-server-related Peakwork components.
