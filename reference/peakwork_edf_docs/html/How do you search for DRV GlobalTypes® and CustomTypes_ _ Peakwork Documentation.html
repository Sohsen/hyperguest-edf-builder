How do you search for DRV GlobalTypes® and CustomTypes?﻿

Last modified: 25 February 2026

The search for a DRV GlobalTypes® or CustomType can be completed successfully,

  • when searching for an exact element that appears in EDF or

  • when searching exactly for multiple elements that appear in the EDF.

The search for one or more DRV GlobalTypes® or CustomTypes is unsuccessful,

  • If the Global/CustomType is not found in the EDF or

  • If there are errors in the way the Types have been listed in the EDF or

  • If, when using a multiple element search, one of the elements has not been defined.
