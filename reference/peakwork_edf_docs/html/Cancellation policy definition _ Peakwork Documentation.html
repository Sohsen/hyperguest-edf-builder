Cancellation policy definition﻿

Last modified: 25 February 2026

This section describes how suppliers and distributors can define non-refundable rates (NRF) or free cancellation policies (FCP) within the hotel EDF.

On how to change cancellation policies as a (dynamic) tour operator using the Box, read the chapter Cancellation of dynamic packages.

Based on DRV GlobalTypes®, resp. CustomTypes, it is possible to enrich EDF with such information. Both non-refundable rates (NRF) or free cancellation policies (FCP) must be added at //HotelRoot/SellingData/Rooms/Room/DRVGlobalTypes@CT.

This approach gives the opportunity to work with all existing components and solutions provided by Peakwork.

note

Disclaimer

In order to implement this solution, an agreement with the German Travel Association (DRV) is required. Please reach out to your contact at Peakwork for more information.

Consider that when sending both refundable and non-refundable rates for the same hotel, only non-refundable rates will be displayed if all other values are the same, see also Hub response. If you want both rates to be displayed, make sure that the hotel contracts they are included in are unique so that the contracts won't be merged.

Free Cancellation Policies﻿

Free Cancellation Policy => FCP

To define a "free cancellation policy" rate, a CustomType can be set on the EDF room level, e.g. "FCP-RATE". (by setting the attribute CT for CustomType in the element: HotelRoot/SellingData/Rooms/Room/DRVGlobalTypes@CT).

This is important to have an identifier to filter for such rates in the Hub search.

Furthermore, the FCP can be set related to a specific period. The FCP itself provides only the information how many days before arrival a specific offer can be cancelled without any charge/fee.

For this, Peakwork uses the official duration pattern of days:

  • https://www.w3.org/TR/xmlschema11-2/#duration

  • https://www.w3schools.com/xml/schema_dtypes_date.asp

Here an example:

<DRVGlobalTypes>
  <DRVGlobalType>
    <GTAttribute GT="GT05" CT="FCP-RATE" />
    <GTAttribute GT="GT05" CT="FCP-P8D" Start="2019-05-01" End="2019-06-30"/>
    <GTAttribute GT="GT05" CT="FCP-P30D" Start="2019-07-01" End="2019-08-30"/>
    <GTAttribute GT="GT05" CT="FCP-P3D" Start="2019-09-01" End="2019-10-31"/>
  </DRVGlobalType>
</DRVGlobalTypes>

The @Start and @End attributes represent the defined travel times for which a given FCP should be applied. In the example above, for travel times between May and June of 2019, free cancellation is offered until 8 days before arrival. For July and August, free cancellation is offered until 30 days before arrival. For September and October, free cancellation is offered until 3 days before arrival.

Note that in case you want this GT to be applied for travels within this start- and end date range only, you must use the DateRestriction element within the Extra element with the attribute/value ApplyTo="Within".

Non-refundable rates﻿

On the other hand, a rate can be non-refundable. For this use case, again a custom DRV GlobalType® can be set:

GT05#NRF-RATE

It looks like this in the EDF:

<DRVGlobalTypes>
  <DRVGlobalType>
    <GTAttribute GT="GT05" CT="NRF-RATE" />
  </DRVGlobalType>
</DRVGlobalTypes>

Free cancellation after booking (grace time)﻿

FCB => Free Cancellation after Booking

To define a free cancellation after booking, a CustomType "FCB-RATE" can be set on the hotel EDF room level.

For example: 4 hours after a booking, a specific offer can be cancelled without any charge/fee.

In addition, a policy can be set related to a specific period.

For this we use the official duration pattern of days/hours:

  • https://www.w3.org/TR/xmlschema11-2/#duration

  • https://www.w3schools.com/xml/schema_dtypes_date.asp

Here an example:

<DRVGlobalTypes>
  <DRVGlobalType>
    <GTAttribute GT="GT05" CT="FCB-RATE" />
    <GTAttribute GT="GT05" CT="FCB-P4H" Start="2019-05-01" End="2019-06-30"/>
    <GTAttribute GT="GT05" CT="FCB-P12H" Start="2019-07-01" End="2019-08-30"/>
    <GTAttribute GT="GT05" CT="FCB-P1D" Start="2019-09-01" End="2019-10-31"/>
  </DRVGlobalType>
</DRVGlobalTypes>
