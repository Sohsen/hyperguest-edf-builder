Reviews﻿

Last modified: 25 February 2026

The Reviews element has to contain at least one element Review. For each Review element the attribute Type specifies the type of review. As of now, this element only is used for the star category of hotels. For this, the Type is set to Category.

In the future other types e.g. overall rating, cleanness etc. will be possible.

The actual value for the review or rating is set within the element Value. For the star rating this might e.g. be 3, 4, 4.5 etc.
